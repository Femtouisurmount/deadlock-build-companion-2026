## 🔥 Why This Exists

Deadlock is still invite-only, but it's already one of the most-played games on Steam — 233K peak, 119K current. The game has 41 heroes and 156 items, and the shop interface doesn't tell you what synergizes with what.

Community build sites like DeadlockLabs exist, but they're browser-based and require you to tab out mid-match. This companion is a local reference. Open it on a second monitor, browse builds, and queue with a plan.

## 🧩 What It Does

### Hero Database
- All 41 heroes with full stats: health, weapon DPS, range, ammo, reload, difficulty
- Filter by role or difficulty
- Compare heroes side by side

### Item Browser
- 156 items across Weapon, Vitality, Spirit
- Filter by tier (800 / 1,600 / 3,200 / 6,400 souls)
- Filter by activation: Passive / Active / Imbue
- View full stat breakdown per item

### Build Presets
- Import community builds from DeadlockLabs build IDs
- Pre-loaded templates for popular heroes: Warden, McGinnis, Haze, Seven, Dynamo
- Create and save your own presets locally

### Skill Path Notes
- Save ability leveling order per hero
- Reference notes for lane matchups and counter items

## ❓ FAQ

**Does this interact with the game?**
No — it's a standalone reference app. No memory reading, no injection, no game file modification.

**Will I get banned?**
Valve does not ban for external reference tools. This app does not read game memory or modify the client. However, use third-party tools at your own discretion in any online game.

**Does it work offline?**
Yes — all data is bundled locally. No internet required after download.

**How often is data updated?**
Hero and item data is updated after major patches. Build presets are community-sourced and may lag behind the latest meta.

**Can I import my own builds?**
Yes — save presets locally and export them as JSON.

**How do I uninstall?**
Delete the companion folder. No registry entries or system changes are made.
